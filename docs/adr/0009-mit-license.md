# ADR-0009 — MIT license for Seeky source

- **Status:** Accepted
- **Date:** 2026-11-26

## Decision

Seeky source code is MIT-licensed. Third-party libraries, runtimes, and model
weights keep their own licenses and notices.

## Consequences

- `LICENSE` and third-party notices ship with the app and with each asset.
- Every dependency, model, runtime, and dataset passes
  [ADR-0022](0022-permissive-license-gate.md).
